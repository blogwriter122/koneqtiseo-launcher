# KoneqtiSEO Launcher

Connects your PC's Chrome browser to the KoneqtiSEO SEO engine.

## Download

Download the latest installer from [Releases](https://github.com/koneqtiseo/koneqtiseo-launcher/releases):
- **Windows**: `KoneqtiSEO-Launcher-Setup.exe`
- **Mac**: `KoneqtiSEO-Launcher.dmg`

## How to Use

1. Download and install the launcher
2. Open it — you'll see a simple window
3. Paste your API key from [koneqtiseo.com/settings](https://koneqtiseo.com/settings)
4. Click **Connect**
5. Green dot = connected. Keep the app running while jobs execute.

The launcher minimizes to your system tray when you close the window.

## Why Do I Need This?

The launcher connects your Chrome browser to the KoneqtiSEO engine. This means:
- SEO scraping uses **your real IP** (no bot detection)
- Publishing uses **your real accounts** (LinkedIn, Reddit, Medium etc.)
- Writing uses **your claude.ai** session (free, no API cost)

Your PC does the browser work. The cloud engine does the intelligence.

## Requirements

- Google Chrome installed
- Windows 10+ or macOS 11+
- Internet connection
